# osTicket IT Service Desk

Implementación de una mesa de servicios IT basada en osTicket.

## Objetivo

Diseñar e implementar una plataforma centralizada para la gestión de solicitudes e incidentes de soporte IT.

## Tecnologías

- Ubuntu Server 24.04
- osTicket
- Apache
- PHP
- MariaDB
- Git
- GitHub
